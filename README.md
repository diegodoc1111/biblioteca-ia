# Las 4 manías de Claude Code y los 4 complementos gratis que las arreglan

Mi biblioteca de recursos de IA: Ponytail, OmniRoute, Graphify y Agent Skills, con su instalación en Claude Code,
más los demás regalos gratis de mi biblioteca.

Hecho por [Diego Osorio](https://instagram.com/soydiegoosorio).

**[👉 Abrir la biblioteca](https://diegodoc1111.github.io/biblioteca-ia/)**

## Fuentes verificadas (29-oct-2026)

- Ponytail: https://github.com/DietrichGebert/ponytail (MIT). Instalación: `/plugin marketplace add DietrichGebert/ponytail`
  y `/plugin install ponytail@ponytail`. Cifras del autor (Ponytail 5, Claude Code, 39 tareas): -53 % código, -26 % costo.
- OmniRoute: https://github.com/cheaper-inference/OmniRoute (MIT). `npm install -g omniroute` (paquete 3.8.52, Node 22 o 24+),
  panel en localhost:20128, `omniroute launch` abre Claude Code a través de OmniRoute (docs/guides/CLAUDE-CODE-CONFIGURATION.md).
  Cifra de sus creadores: ~1.620 millones de tokens al mes sumando planes gratis de terceros, con tus propias cuentas.
- Graphify: https://github.com/Graphify-Labs/graphify (Apache-2.0). `uv tool install graphifyy` + `graphify install`
  (PyPI `graphifyy` 0.9.97, Python 3.10+). El código se mapea en local con tree-sitter, sin LLM.
- Agent Skills de Addy Osmani: https://github.com/addyosmani/agent-skills (MIT). `/plugin marketplace add addyosmani/agent-skills`
  y `/plugin install agent-skills@addy-agent-skills`; comandos /spec, /plan, /build, /test, /ship.
- Comandos de instalación de Claude Code: https://code.claude.com/docs/en/setup.
